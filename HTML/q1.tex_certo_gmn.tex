(Atividade \emph{Warmup C++}) Elabore um programa em C++ que receba uma sequência de valores inteiros. A sequência termina com a entrada -1. Em seguida, o programa recebe um valor $k$.

A saída do programa deve ser os $k$ menores elementos da sequência ordenados. É fortemente recomendado que se utilize os recursos da biblioteca padrão do C++ \emph{Standard Template Library} (STL) (ex. \texttt{vector}, \texttt{pair}, etc.). Observação: uma solução trivial resolve o problema em $O(nk)$ e a solução utilizando uma estrutura de dados adequada resolve em $O(k \log n)$.
